روش‌های افزودن کد JavaScript به HTML (internal, external, inline)

توضیح آموزشی

کد می‌تواند در ویژگی HTML (inline)، تگ script (internal) یا فایل جدا (external) باشد؛ فایل جداگانه نگهداری ساده‌تری دارد.

کد inline داخل ویژگی رویداد نوشته می‌شود، اما نگهداری آن دشوار است. کد internal در تگ script قرار می‌گیرد و فایل external با src بارگذاری می‌شود. فایل جداگانه معمولاً انتخاب مناسب‌تری است. ویژگی defer اجرای فایل را تا پس از تجزیه HTML عقب می‌اندازد. در DevTools، زبانه‌های Console و Sources برای دیدن خطاها، اجرای دستور و توقف مرحله‌ای کاربرد دارند.

کد نمونه

const area = document.querySelector("#demoArea");
const button = document.createElement("button");
button.textContent = "اجرای کد صفحه";
button.addEventListener("click", () => console.log("handler متصل شد"));
area.append(button);
console.log(
  "inline در ویژگی HTML نوشته می‌شود؛ internal داخل script و external در فایل جدا با src قرار می‌گیرد.",
);

راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.
