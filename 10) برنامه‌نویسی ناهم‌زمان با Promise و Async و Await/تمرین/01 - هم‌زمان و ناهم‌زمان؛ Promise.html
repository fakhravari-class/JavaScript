10) برنامه‌نویسی ناهم‌زمان با Promise و Async و Await

هم‌زمان و ناهم‌زمان؛ Promise

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

مفهوم ناهم‌زمانی (Asynchronous) در جاوااسکریپت و تفاوت آن با اجرای هم‌زمان (Synchronous)

توضیح آموزشی

اجرای هم‌زمان خط بعدی را بلافاصله انجام می‌دهد؛ ناهم‌زمانی کار طولانی را بدون مسدود کردن ادامهٔ برنامه مدیریت می‌کند.

کد هم‌زمان مرحله‌به‌مرحله جلو می‌رود و یک کار کند می‌تواند ادامه را منتظر نگه دارد. عملیات شبکه‌ای ناهم‌زمان نتیجه را بعداً می‌دهد و رابط را آزاد می‌گذارد. Promise نمایندهٔ نتیجهٔ آینده است و سه حالت pending، fulfilled و rejected دارد. then برای نتیجه و catch برای خطا به‌کار می‌روند؛ هر then می‌تواند مقدار بعدی زنجیره را بسازد.

کد نمونه

console.log("اول اجرا می‌شود");
setTimeout(() => console.log("بعداً اجرا می‌شود"), 0);
console.log("دستور هم‌زمان بعدی");

راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.

حالات Promise: pending، fulfilled، rejected
توضیح آموزشی
Promise از pending شروع می‌شود و فقط یک‌بار به fulfilled یا rejected می‌رسد.
کد هم‌زمان مرحله‌به‌مرحله جلو می‌رود و یک کار کند می‌تواند ادامه را منتظر نگه دارد. عملیات شبکه‌ای ناهم‌زمان نتیجه را بعداً می‌دهد و رابط را آزاد می‌گذارد. Promise نمایندهٔ نتیجهٔ آینده است و سه حالت pending، fulfilled و rejected دارد. then برای نتیجه و catch برای خطا به‌کار می‌روند؛ هر then می‌تواند مقدار بعدی زنجیره را بسازد.
کد نمونه
let state = "pending";
const task = new Promise((resolve) =>
  setTimeout(() => resolve("داده آماده شد"), 50),
);
console.log("حالت آغازین:", state);
await task;
state = "fulfilled";
console.log("حالت موفق:", state);
try {
  await Promise.reject(Error("نمونه رد شد"));
} catch (e) {
  state = "rejected";
  console.log("حالت خطا:", state, e.message);
}

زنجیره‌سازی درخواست‌ها با .then() و .catch()
توضیح آموزشی
then مقدار موفق را تبدیل یا تحویل می‌دهد؛ catch خطا را می‌گیرد و می‌تواند زنجیره را بازیابی کند.
کد هم‌زمان مرحله‌به‌مرحله جلو می‌رود و یک کار کند می‌تواند ادامه را منتظر نگه دارد. عملیات شبکه‌ای ناهم‌زمان نتیجه را بعداً می‌دهد و رابط را آزاد می‌گذارد. کد نمونه
Promise.resolve(4)
  .then((value) => value * 2)
  .then((value) => console.log(value))
  .catch((error) => console.log(error.message));
