Callback و زمان‌بندی

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

تفاوت بین Callback، Promise و async/await از نظر خوانایی و کنترل خطا

توضیح آموزشی

Callback تابعی است که بعداً فراخوانی می‌شود؛ Promise زنجیره‌پذیر است و async/await خواندن جریان را ساده می‌کند.

Callback تابعی است که برای اجرای بعدی به تابع دیگری سپرده می‌شود؛ رویدادها و زمان‌سنج‌ها از آن استفاده می‌کنند. زنجیره‌های callback تو در تو خوانایی را کم می‌کنند، و Promise و async/await راهی برای ساختار بهترند. setTimeout یک کار را پس از حداقل تأخیر صف‌بندی می‌کند؛ setInterval تکرارش می‌کند و باید در پایان با clearInterval متوقف شود.

کد نمونه

function withCallback(done) {
  done("callback");
}
withCallback((value) => console.log(value));
Promise.resolve("promise").then(console.log);
async function modern() {
  console.log(await Promise.resolve("async/await"));
}
await modern();

راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.

استفاده از setTimeout() و setInterval() برای شبیه‌سازی عملیات زمان‌دار
توضیح آموزشی
setTimeout یک بار و setInterval تکراری زمان‌بندی می‌کند؛ شناسهٔ برگشتی برای لغو timer استفاده می‌شود.
Callback تابعی است که برای اجرای بعدی به تابع دیگری سپرده می‌شود؛ رویدادها و زمان‌سنج‌ها از آن استفاده می‌کنند. زنجیره‌های callback تو در تو خوانایی را کم می‌کنند، و Promise و async/await راهی برای ساختار بهترند. setTimeout یک کار را پس از حداقل تأخیر صف‌بندی می‌کند؛ setInterval تکرارش می‌کند و باید در پایان با clearInterval متوقف شود.
کد نمونه
let count = 0;
const timer = setInterval(() => {
  count++;
  console.log("تکرار", count);
  if (count === 2) clearInterval(timer);
}, 100);
setTimeout(() => console.log("setTimeout یک‌بار اجرا می‌شود"), 50);
