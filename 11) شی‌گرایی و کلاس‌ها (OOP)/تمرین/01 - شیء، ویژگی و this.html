مفهوم Object و Property

توضیح آموزشی

Object مجموعه‌ای از Propertyهاست؛ هر Property نام (key) و مقدار دارد.

شیء مجموعه‌ای از کلید و مقدار است؛ ویژگی داده و متد تابع وابسته به شیء است. Object Literal ساده‌ترین راه ساخت است. this به شیوهٔ فراخوانی تابع وابسته است؛ در متد obj.method مقدار this همان obj است، اما تابع پیکانی this تازه‌ای نمی‌سازد و this بیرونی را می‌گیرد. برای ساخت چند شیء مشابه از class یا سازنده استفاده کنید.

کد نمونه

const user = { name: "سارا", active: true };
console.log(user.name, user.active);

متدها و کلمه کلیدی this
توضیح آموزشی
متد تابعِ متعلق به شیء است و this هنگام فراخوانی معمولی به شیء صاحب فراخوانی اشاره می‌کند.
شیء مجموعه‌ای از کلید و مقدار است؛ ویژگی داده و متد تابع وابسته به شیء است. Object Literal ساده‌ترین راه ساخت است. this به شیوهٔ فراخوانی تابع وابسته است؛ در متد obj.method مقدار this همان obj است، اما تابع پیکانی this تازه‌ای نمی‌سازد و this بیرونی را می‌گیرد. برای ساخت چند شیء مشابه از class یا سازنده استفاده کنید.
کد نمونه
const user = {
  name: "سارا",
  greet() {
    return "سلام " + this.name;
  },
};
console.log(user.greet());
راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.

شیء داخلی Math و عملیات عددی
توضیح آموزشی
Math یک شیء داخلی JavaScript برای ثابت‌ها و محاسبه‌های عددی است و نیازی به ساختن نمونه با new ندارد.
از Math.PI برای عدد پی و از متدهایی مانند max، min، round، floor، ceil و random استفاده می‌شود. مقدار random بین صفر و یک است؛ برای ساخت عدد صحیح در بازه، آن را مقیاس‌بندی و گرد کنید.
کد نمونه
console.log("عدد پی:", Math.PI);
console.log("بزرگ‌ترین و کوچک‌ترین:", Math.max(3, 9, 4), Math.min(3, 9, 4));
console.log("گرد کردن:", Math.round(4.6), Math.floor(4.6), Math.ceil(4.1));
const dice = Math.floor(Math.random() * 6) + 1;
console.log("عدد تصادفی تاس:", dice);
راهنمای اجرا: مقادیر ثابت و خروجی چند متد را در خروجی ببینید.
