12) کار با اشیاء پیشرفته در JavaScript

تغییر ویژگی و freeze

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

قفل‌کردن اشیاء با Object.freeze() و جلوگیری از تغییر داده‌ها

توضیح آموزشی

Object.freeze افزودن، حذف و تغییر ویژگی‌های سطح اول را می‌بندد؛ فریز سطحی است و شیء تو‌در‌تو جداگانه فریز نمی‌شود.

می‌توان ویژگی را با نقطه یا براکت افزود و با delete حذف کرد. Object.freeze تغییر ویژگی‌های سطح اول را منع می‌کند، اما سطحی است و اشیای تو در تو را خودکار فریز نمی‌کند. در حالت سخت‌گیرانه تلاش برای تغییر ممکن است TypeError بدهد؛ برای دادهٔ قابل‌اعتماد، به freeze به‌تنهایی به‌عنوان کنترل امنیتی تکیه نکنید.

کد نمونه

"use strict";
const settings = Object.freeze({ theme: "light" });
try {
  settings.theme = "dark";
} catch (e) {
  console.log(e.name);
}
console.log(settings.theme);
