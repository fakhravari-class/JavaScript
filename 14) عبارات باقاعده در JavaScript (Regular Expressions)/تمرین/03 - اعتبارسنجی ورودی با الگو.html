14) عبارات باقاعده در JavaScript (Regular Expressions)

اعتبارسنجی ورودی با الگو

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

استفاده برای اعتبارسنجی ایمیل، شماره و رمز عبور

توضیح آموزشی

Regex می‌تواند قواعد شکلی ایمیل، شماره و رمز را بررسی کند، اما اعتبار واقعی را جایگزین تأیید سرور نمی‌کند.

Regex برای کنترل قالب‌هایی مانند عدد، کدپستی یا شکل سادهٔ ایمیل مفید است، اما جای اعتبارسنجی کامل سمت سرور را نمی‌گیرد. پیام خطا باید روشن باشد و ورودی پیش از ذخیره نیز پاک‌سازی و بررسی شود. برای رمز عبور بهتر است هر شرط را جداگانه بسنجید تا علت رد شدن را توضیح دهید.

کد نمونه

const email = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const password = /^(?=.*\d)(?=.*[^\w\s]).{8,}$/;
console.log(email.test("sara@example.com"), password.test("Learn#2026"));

راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.

ترکیب Regex با شرط‌ها در فرم‌ها
توضیح آموزشی
اعتبارسنجی Regex باید هنگام رویداد فرم انجام شود و پیام خطا را نزدیک ورودی نشان دهد.
Regex برای کنترل قالب‌هایی مانند عدد، کدپستی یا شکل سادهٔ ایمیل مفید است، اما جای اعتبارسنجی کامل سمت سرور را نمی‌گیرد. پیام خطا باید روشن باشد و ورودی پیش از ذخیره نیز پاک‌سازی و بررسی شود. برای رمز عبور بهتر است هر شرط را جداگانه بسنجید تا علت رد شدن را توضیح دهید.
کد نمونه
const value = "A7!";
const valid = /^[A-Za-z0-9!@#]{3,10}$/.test(value);
console.log(valid ? "ورودی پذیرفته شد" : "ورودی نامعتبر است");
