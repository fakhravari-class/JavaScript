16) کار با رویدادها در JavaScript

رویداد و addEventListener

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

رویدادهای رایج: click، mouseover، keydown، submit

توضیح آموزشی

click، mouseover، keydown و submit نمونهٔ رویدادهای کاربرند؛ هر رویداد اطلاعاتی در شیء event دارد.

رویداد نشان می‌دهد کاربر یا مرورگر کاری انجام داده است. click، mouseover، keydown و submit نمونه‌اند. addEventListener تابعی ثبت می‌کند که هنگام رویداد اجرا می‌شود؛ شیء event اطلاعات رویداد و target عنصر آغازکننده را دارد. برای callback نام‌دار می‌توان بعداً removeEventListener کرد.

کد نمونه

const button = document.createElement("button");
button.textContent = "کلیک کنید";
button.addEventListener("click", (event) =>
  console.log(event.type, event.currentTarget === button),
);
document.querySelector("#demoArea").append(button);

راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.

افزودن event با addEventListener
توضیح آموزشی
addEventListener تابع واکنش به رویداد را ثبت می‌کند و چند شنونده را بدون بازنویسی ویژگی‌های عنصر می‌پذیرد.
رویداد نشان می‌دهد کاربر یا مرورگر کاری انجام داده است. click، mouseover، keydown و submit نمونه‌اند. addEventListener تابعی ثبت می‌کند که هنگام رویداد اجرا می‌شود؛ شیء event اطلاعات رویداد و target عنصر آغازکننده را دارد. برای callback نام‌دار می‌توان بعداً removeEventListener کرد.
کد نمونه
const button = document.createElement("button");
button.textContent = "ثبت";
button.addEventListener("click", () =>
  console.log("رویداد با addEventListener اجرا شد"),
);
document.querySelector("#demoArea").append(button);
راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.

رویدادهای focus، blur، change، dblclick و load
توضیح آموزشی
علاوه بر click و keydown، تغییر تمرکز ورودی، تغییر مقدار انتخابی، دوبارکلیک و بارگذاری منبع هم رویداد تولید می‌کنند.
focus هنگام ورود تمرکز به کنترل، blur هنگام خروج، change پس از تغییر مقدار، و dblclick پس از دو بار کلیک اجرا می‌شود. رویداد load برای کامل‌شدن بارگذاری منبعی مانند تصویر است. برای ثبت هرکدام از addEventListener استفاده کنید.
کد نمونه
const area = document.querySelector("#demoArea");
area.innerHTML = `
  <label>متن: <input class="event-input" value="نمونه"></label>
  <label>گزینه:
    <select class="event-select">
      <option>یک</option>
      <option>دو</option>
    </select>
  </label>
  <button class="event-double">دوبار کلیک</button>
`;
const input = area.querySelector(".event-input");
const select = area.querySelector(".event-select");
const button = area.querySelector(".event-double");
input.addEventListener("focus", () => console.log("focus: ورودی انتخاب شد"));
input.addEventListener("blur", () => console.log("blur: تمرکز از ورودی خارج شد"));
select.addEventListener("change", () => console.log("change:", select.value));
button.addEventListener("dblclick", () => console.log("dblclick: دو بار کلیک شد"));
const image = new Image();
image.addEventListener("load", () => console.log("load: تصویر بارگذاری شد"));
image.src = "data:image/gif;base64,R0lGODlhAQABAAD/ACwAAAAAAQABAAACADs=";
area.append(image);
راهنمای اجرا: ورودی را انتخاب و رها کنید، گزینه را عوض کنید، دکمه را دوبار بزنید و پیام بارگذاری تصویر را ببینید.
