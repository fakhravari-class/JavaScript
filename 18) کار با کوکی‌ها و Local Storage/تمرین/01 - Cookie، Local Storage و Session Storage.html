18) کار با کوکی‌ها و Local Storage

Cookie، Local Storage و Session Storage

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

مفهوم کوکی (Cookie) و کاربرد آن

توضیح آموزشی

Cookie در درخواست‌های وب می‌تواند به سرور فرستاده شود؛ Local Storage و Session Storage در مرورگر می‌مانند و خودکار به سرور ارسال نمی‌شوند.

Cookie همراه درخواست به سرور ارسال می‌شود و برای نشست و تنظیمات سمت سرور کاربرد دارد. Local Storage رشته‌ها را تا حذف دستی نگه می‌دارد؛ Session Storage به نشست تب وابسته است و خودکار با هر درخواست ارسال نمی‌شود. هیچ‌کدام جای پایگاه امن برای رازها نیستند؛ دادهٔ قابل‌دسترسی از JavaScript نباید توکن حساس تلقی شود.

کد نمونه

document.cookie = "course-demo=js; max-age=3600; path=/; SameSite=Lax";
console.log("کوکی:", document.cookie);
try {
  localStorage.setItem("demo", "پایدارتر از نشست");
  sessionStorage.setItem("demo", "موقت در نشست");
  console.log(
    "local:",
    localStorage.getItem("demo"),
    "session:",
    sessionStorage.getItem("demo"),
  );
} catch (e) {
  console.log("ذخیره‌سازی در این محیط محدود است:", e.name);
}

Local Storage و Session Storage
توضیح آموزشی
Local Storage بین نشست‌های مرورگر باقی می‌ماند؛ Session Storage معمولاً تا پایان تب/نشست نگه داشته می‌شود و هر دو متن ذخیره می‌کنند.
Cookie همراه درخواست به سرور ارسال می‌شود و برای نشست و تنظیمات سمت سرور کاربرد دارد. Local Storage رشته‌ها را تا حذف دستی نگه می‌دارد؛ Session Storage به نشست تب وابسته است و خودکار با هر درخواست ارسال نمی‌شود. هیچ‌کدام جای پایگاه امن برای رازها نیستند؛ دادهٔ قابل‌دسترسی از JavaScript نباید توکن حساس تلقی شود.
کد نمونه
const profile = { name: "سارا", lastVisit: new Date().toISOString() };
try {
  localStorage.setItem("profile-demo", JSON.stringify(profile));
  sessionStorage.setItem(
    "draft-demo",
    JSON.stringify({ text: "یادداشت موقت" }),
  );
  console.log(
    JSON.parse(localStorage.getItem("profile-demo")),
    JSON.parse(sessionStorage.getItem("draft-demo")),
  );
} catch (e) {
  console.log("ذخیره‌سازی در این محیط محدود است:", e.name);
}

تفاوت آن‌ها با کوکی
توضیح آموزشی
Cookie معمولاً محدودتر است و به درخواست HTTP می‌چسبد؛ Local/Session Storage از JavaScript خوانده می‌شوند و زمان ماندگاری متفاوت دارند.
کد نمونه
const record = { name: "سارا" };
try {
  localStorage.setItem("lifetime-demo", JSON.stringify(record));
  sessionStorage.setItem("session-demo", JSON.stringify(record));
  document.cookie = "cookie-demo=active; max-age=3600; path=/; SameSite=Lax";
  console.log(
    "Local Storage تا پاک‌کردن می‌ماند؛ Session Storage برای نشست است؛ Cookie دارای تنظیم انقضاست.",
  );
} catch (e) {
  console.log("محدودیت مرورگر:", e.name);
}
راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.
