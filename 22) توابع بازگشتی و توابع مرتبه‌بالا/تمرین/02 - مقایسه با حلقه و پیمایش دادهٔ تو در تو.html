مقایسهٔ بازگشت با حلقه‌ها (Loop vs Recursion)

توضیح آموزشی

حلقه معمولاً حافظهٔ پشتهٔ کمتری می‌خواهد؛ بازگشت می‌تواند ساختار بازگشتی را خواناتر بیان کند.

حلقه برای تکرار خطی معمولاً کم‌هزینه و روشن است؛ بازگشت برای ساختار درختی یا تعریف ریاضی مناسب است. مجموع آرایه را می‌توان با accumulator در حلقه حساب کرد یا عنصر نخست را با مجموع بقیه ترکیب کرد. برای ورودی عمیق، نسخهٔ حلقه‌ای از سرریز پشته دوری می‌کند.

کد نمونه

function sumLoop(values) {
  let result = 0;
  for (const value of values) result += value;
  return result;
}
function sumRecursive(values, i = 0) {
  return i === values.length ? 0 : values[i] + sumRecursive(values, i + 1);
}
console.log(sumLoop([1, 2, 3]), sumRecursive([1, 2, 3]));

راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.

کد نمونه
function flatten(values) {
  return values.reduce(
    (all, item) => all.concat(Array.isArray(item) ? flatten(item) : item),
    [],
  );
}
console.log(flatten([1, [2, [3]], 4]));
