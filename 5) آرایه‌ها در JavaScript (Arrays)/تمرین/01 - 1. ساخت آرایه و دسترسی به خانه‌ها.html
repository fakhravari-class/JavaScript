5) آرایه‌ها در JavaScript (Arrays)

1. ساخت آرایه و دسترسی به خانه‌ها

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

تعریف آرایه و نحوهٔ مقداردهی اولیه : [ ]

توضیح آموزشی

آرایه فهرستی مرتب از مقدارهاست؛ اندیس‌ها از صفر شروع می‌شوند و آرایه می‌تواند انواع مختلف داشته باشد.

آرایه چند مقدار را با ترتیب مشخص نگه می‌دارد. اندیس از صفر آغاز می‌شود و length تعداد عنصرها را نشان می‌دهد. دسترسی به اندیس ناموجود undefined می‌دهد. آرایه‌ها مرجع‌محور و قابل‌تغییرند؛ const مانع انتساب آرایهٔ تازه به متغیر می‌شود، نه تغییر خانه‌های آن.

کد نمونه

const scores = [18, 14, 20];
console.log(scores);

راهنمای اجرا: برای دیدن نتیجه، دکمهٔ «اجرای مثال» را بزنید؛ خروجی زیر کد نمایش داده می‌شود.

const colors = ["قرمز", "سبز", "آبی"];
console.log(colors[0], colors[colors.length - 1]);
