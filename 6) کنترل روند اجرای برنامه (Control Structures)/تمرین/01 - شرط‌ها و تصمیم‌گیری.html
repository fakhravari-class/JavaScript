6) کنترل روند اجرای برنامه (Control Structures)

شرط‌ها و تصمیم‌گیری

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

شرط‌ها: if، else if، switch

توضیح آموزشی

if و else if شرط‌ها را به‌ترتیب می‌سنجند؛ switch برای انتخاب میان چند مقدار مشخص خواناتر است.

if کد را فقط هنگام درست‌بودن شرط اجرا می‌کند؛ else if چند حالت را به ترتیب می‌سنجد و else حالت پیش‌فرض است. switch برای مقایسهٔ یک مقدار با چند case مناسب است و break از ادامه‌افتادن به case بعدی جلوگیری می‌کند. شرط‌ها باید مقدار boolean داشته باشند؛ عملگرهای &&، || و ! امکان ترکیب آن‌ها را می‌دهند.

کد نمونه

const score = 17;
if (score >= 18) console.log("عالی");
else if (score >= 10) console.log("قبول");
else console.log("تلاش دوباره");
const role = "editor";
switch (role) {
  case "admin":
    console.log("مدیر");
    break;
  case "editor":
    console.log("ویرایشگر");
    break;
  default:
    console.log("کاربر");
}

حلقه‌ها: for، while، do...while، forEach
توضیح آموزشی
for، while و do...while حلقه‌اند؛ forEach روی عضوهای آرایه اجرا می‌شود و به break/continue مستقیم پاسخ نمی‌دهد.
if کد را فقط هنگام درست‌بودن شرط اجرا می‌کند؛ else if چند حالت را به ترتیب می‌سنجد و else حالت پیش‌فرض است. switch برای مقایسهٔ یک مقدار با چند case مناسب است و break از ادامه‌افتادن به case بعدی جلوگیری می‌کند. شرط‌ها باید مقدار boolean داشته باشند؛ عملگرهای &&، || و ! امکان ترکیب آن‌ها را می‌دهند.
کد نمونه
for (let i = 1; i <= 3; i++) console.log("for", i);
let n = 0;
while (n < 2) {
  console.log("while", n);
  n++;
}
let tries = 0;
do {
  tries++;
} while (tries < 1);
["الف", "ب"].forEach((x) => console.log(x));

عملگرهای منطقی AND، OR، NOT
توضیح آموزشی
AND فقط وقتی درست است که هر دو شرط درست باشند؛ OR با درست‌بودن یکی کافی است و NOT مقدار را برعکس می‌کند.
if کد را فقط هنگام درست‌بودن شرط اجرا می‌کند؛ else if چند حالت را به ترتیب می‌سنجد و else حالت پیش‌فرض است. switch برای مقایسهٔ یک مقدار با چند case مناسب است و break از ادامه‌افتادن به case بعدی جلوگیری می‌کند. شرط‌ها باید مقدار boolean داشته باشند؛ عملگرهای &&، || و ! امکان ترکیب آن‌ها را می‌دهند.
کد نمونه
const age = 22,
  hasCard = false;
console.log(age >= 18 && hasCard, age < 18 || hasCard, !hasCard);
