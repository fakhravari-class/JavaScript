تعریف و ساختار JSON : کلید–مقدار، انواع دادهٔ مجاز

توضیح آموزشی

JSON قالب متنی تبادل داده با ساختار کلید-مقدار است؛ رشته‌ها باید دابل‌کوتیشن داشته باشند و تابع/undefined در آن مجاز نیست.

JSON قالب متنی تبادل داده است. کلیدها و رشته‌ها باید در کوتیشن دوتایی باشند؛ مقدار مجاز شامل رشته، عدد، boolean، null، آرایه و شیء است. تابع، undefined و کامنت در JSON معتبر نیستند. JSON شبیه نوشتار شیء جاوااسکریپت است اما قواعد سخت‌گیرانه‌تری دارد.

کد نمونه

const user = { name: "سارا", age: 21, active: true, tags: ["js", "web"] };
console.log(JSON.stringify(user));

تفاوت JSON با اشیای JavaScript و نکات سازگاری
توضیح آموزشی
شیء JavaScript مقدار اجرایی در حافظه است؛ JSON متن استانداردی برای انتقال/ذخیره است و بعضی نوع‌های JS را پوشش نمی‌دهد.
JSON قالب متنی تبادل داده است. کلیدها و رشته‌ها باید در کوتیشن دوتایی باشند؛ مقدار مجاز شامل رشته، عدد، boolean، null، آرایه و شیء است. تابع، undefined و کامنت در JSON معتبر نیستند. JSON شبیه نوشتار شیء جاوااسکریپت است اما قواعد سخت‌گیرانه‌تری دارد.
کد نمونه
const object = { name: "سارا" };
const json = JSON.stringify(object);
console.log(typeof object, typeof json, JSON.parse(json).name);
