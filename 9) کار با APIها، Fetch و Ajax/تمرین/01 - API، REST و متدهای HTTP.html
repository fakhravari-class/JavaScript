9) کار با APIها، Fetch و Ajax

API، REST و متدهای HTTP

برای هر مبحث، آموزش، مثال قابل اجرا و تمرین را باز کنید.

مفهوم API (Application Programming Interface) و اصول ارتباط با سرویس‌های RESTful

توضیح آموزشی

API قرارداد تعامل دو نرم‌افزار است؛ REST معمولاً منابع را با URL و عملیات HTTP بدون نگهداری وضعیت درخواست قبلی مدیریت می‌کند.

API قرارداد درخواست و پاسخ میان برنامه‌هاست. در REST معمولاً URL منبع را مشخص می‌کند و متد HTTP نوع کار را: GET برای خواندن، POST برای ایجاد، PUT برای جایگزینی، PATCH برای تغییر جزئی و DELETE برای حذف. وضعیت HTTP مثل 200 یا 404 نتیجه را نشان می‌دهد. مرورگر به سرور وصل می‌شود و معمولاً داده را به شکل JSON می‌فرستد.

کد نمونه

const api = {
  name: "JSONPlaceholder",
  base: "https://jsonplaceholder.typicode.com",
};
console.log("API:", api.name, "REST resource:", api.base + "/users");

استفاده از JSONPlaceholder یا سایر APIهای تست برای تمرین
توضیح آموزشی
JSONPlaceholder API آزمایشی برای تمرین GET و POST است؛ داده‌های آن واقعی و پایدار ذخیره نمی‌شوند.
API قرارداد درخواست و پاسخ میان برنامه‌هاست. در REST معمولاً URL منبع را مشخص می‌کند و متد HTTP نوع کار را: GET برای خواندن، POST برای ایجاد، PUT برای جایگزینی، PATCH برای تغییر جزئی و DELETE برای حذف. وضعیت HTTP مثل 200 یا 404 نتیجه را نشان می‌دهد. مرورگر به سرور وصل می‌شود و معمولاً داده را به شکل JSON می‌فرستد.
کد نمونه
async function sampleApi() {
  try {
    const r = await fetch("https://jsonplaceholder.typicode.com/users/1");
    console.log("وضعیت:", r.status, await r.json());
  } catch (e) {
    console.log("API آزمایشی در دسترس نیست:", e.message);
  }
}
await sampleApi();
