کار با Fetch API برای دریافت و ارسال داده

توضیح آموزشی

Fetch API درخواست HTTP را با Promise می‌فرستد و پاسخ را به شکل Response تحویل می‌دهد.

fetch یک Promise برمی‌گرداند. Promise آن با پاسخ HTTP مانند 404 هم resolve می‌شود؛ پس response.ok را جداگانه بررسی کنید. سپس response.json() خودش ناهم‌زمان است. رابط کاربری بهتر است سه وضعیت loading، success و error را نشان دهد و دادهٔ دریافتی را با createElement و textContent وارد DOM کند.

کد نمونه

const options = {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "سارا" }),
};
console.log(options);

استفاده از fetch برای واکشی داده
توضیح آموزشی
fetch(url) درخواست GET می‌فرستد؛ JSON پاسخ را باید جداگانه با response.json خواند.
fetch یک Promise برمی‌گرداند. Promise آن با پاسخ HTTP مانند 404 هم resolve می‌شود؛ پس response.ok را جداگانه بررسی کنید. سپس response.json() خودش ناهم‌زمان است. رابط کاربری بهتر است سه وضعیت loading، success و error را نشان دهد و دادهٔ دریافتی را با createElement و textContent وارد DOM کند.
کد نمونه
async function load() {
  try {
    const r = await fetch("https://jsonplaceholder.typicode.com/users/1");
    if (!r.ok) throw Error("HTTP " + r.status);
    console.log(await r.json());
  } catch (e) {
    console.log("درخواست ناموفق:", e.message);
  }
}
await load();

مدیریت پاسخ با then و catch
توضیح آموزشی
then نتیجهٔ Promise موفق را به مرحلهٔ بعد می‌برد و catch خطاهای زنجیره را می‌گیرد.
fetch یک Promise برمی‌گرداند. Promise آن با پاسخ HTTP مانند 404 هم resolve می‌شود؛ پس response.ok را جداگانه بررسی کنید. سپس response.json() خودش ناهم‌زمان است. رابط کاربری بهتر است سه وضعیت loading، success و error را نشان دهد و دادهٔ دریافتی را با createElement و textContent وارد DOM کند.
کد نمونه
fetch("https://jsonplaceholder.typicode.com/users/1")
  .then((r) => {
    if (!r.ok) throw Error("HTTP " + r.status);
    return r.json();
  })
  .then((user) => console.log(user.name))
  .catch((e) => console.log("خطا:", e.message));

استفاده از async/await برای نوشتن کد تمیزتر
توضیح آموزشی
async/await همان Promise را با ظاهر ترتیبی می‌نویسد؛ await فقط در تابع async یا محیط ماژول مجاز است.
fetch یک Promise برمی‌گرداند. Promise آن با پاسخ HTTP مانند 404 هم resolve می‌شود؛ پس response.ok را جداگانه بررسی کنید. سپس response.json() خودش ناهم‌زمان است. رابط کاربری بهتر است سه وضعیت loading، success و error را نشان دهد و دادهٔ دریافتی را با createElement و textContent وارد DOM کند.
کد نمونه
async function getUser() {
  try {
    const r = await fetch("https://jsonplaceholder.typicode.com/users/1");
    const user = await r.json();
    console.log(user.name);
  } catch (e) {
    console.log(e.message);
  }
}
await getUser();
