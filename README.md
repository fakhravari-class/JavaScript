# آموزش طراحی وب: HTML، CSS و JavaScript

این مخزن مجموعه‌ای از جزوه‌ها، نمونه‌کدها، تمرین‌ها و منابع آموزشی برای یادگیری مبانی طراحی و برنامه‌نویسی وب است. مطالب به زبان فارسی تهیه شده‌اند و از آشنایی با ساختار صفحه‌های وب تا تعامل با مرورگر، کار با داده و ساخت پروژه‌های کوچک را پوشش می‌دهند.

این مخزن یک برنامهٔ نرم‌افزاری واحد نیست و برای اجرا به فرایند build یا نصب وابستگی‌های پروژه نیاز ندارد. فایل‌های آموزشی را می‌توان مستقیماً باز کرد؛ برای تمرین‌های HTML، مرورگر و یک ویرایشگر متن کافی است.

## مسیر پیشنهادی یادگیری

۱. **HTML**: ساختار سند، متن و پیوندها، تصویر، فهرست، جدول، فرم و بخش‌بندی معنایی صفحه را یاد بگیرید.
۲. **CSS**: انتخابگرها، رنگ و تایپوگرافی، مدل جعبه، چیدمان، Flexbox، Grid، واکنش‌گرایی و سازمان‌دهی کد را تمرین کنید.
۳. **JavaScript**: ابتدا زبان و داده‌ها را یاد بگیرید، سپس با DOM و رویدادها به صفحه رفتار اضافه کنید و بعد سراغ درخواست‌های شبکه و مفاهیم پیشرفته‌تر بروید.
۴. **پروژه**: آموخته‌ها را در مثال‌های یکپارچهٔ دوره به کار بگیرید و کدها را تغییر دهید و دوباره در مرورگر اجرا کنید.

## اجرای مثال‌ها

1. مخزن را با Git دریافت کنید یا فایل‌های آن را دانلود کنید.
2. پوشهٔ موضوع یا جلسهٔ موردنظر را باز کنید.
3. برای مطالعه، فایل `.docx` یا `.pdf` را با برنامهٔ مناسب باز کنید.
4. برای اجرای تمرین، فایل `.html` را در مرورگر باز کنید. در صورت نیاز به ویرایش، آن را با VS Code یا ویرایشگر دیگری باز کنید.
5. تغییر کد را ذخیره و صفحه را در مرورگر تازه‌سازی کنید. برای دیدن خروجی `console.log`، ابزار توسعه‌دهندهٔ مرورگر را باز کنید و به زبانهٔ **Console** بروید.

بعضی مثال‌ها از API یا منبع بیرونی استفاده می‌کنند و برای اجرا به اینترنت نیاز دارند. همچنین مرورگر ممکن است درخواست‌های شبکه را هنگام بازکردن فایل با نشانی `file://` محدود کند؛ در این حالت فایل را با یک وب‌سرور توسعهٔ محلی، مانند افزونهٔ Live Server در VS Code، اجرا کنید.

## ابزارهای موردنیاز

- یک مرورگر به‌روز مانند Chrome، Firefox یا Edge
- ویرایشگر متن یا کد، مانند Visual Studio Code
- برنامه‌ای برای مشاهدهٔ PDF و فایل‌های Word
- اینترنت برای مثال‌هایی که به APIها یا منابع بیرونی متصل می‌شوند

برای مثال‌های پایهٔ HTML، CSS و JavaScript به نصب Node.js یا ابزار build نیاز نیست. Node.js فقط برای مثال‌ها یا پروژه‌هایی لازم است که صریحاً از محیط سمت سرور یا ابزارهای آن استفاده کنند.

## آشنایی با ساختار دورهٔ جامع

در پوشهٔ `Web Design Fundamental (HTML5, CSS3, JavaScript)`، محتوای دوره به این شکل دسته‌بندی شده است:

- `Class HTML`، `Class CSS` و `Class JavaScript`: درس‌ها و تمرین‌های هر فناوری.
- `سرفصل کلی`: اسناد کلی و مطالب تکمیلی.
- `cheatsheets`: برگه‌های مرجع تصویری HTML، CSS و JavaScript.
- `image` و `video`: تصاویر و ویدئوهای همراه آموزش.
- `Project` یا پوشه‌های پروژه: نمونه‌های یکپارچه برای تمرین عملی.

ساختار هر درس ممکن است با توجه به موضوع کمی تفاوت داشته باشد؛ فایل‌های Word/PDF برای مطالعه و فایل‌های HTML برای اجرای مثال‌ها هستند.

## مشارکت و نگهداری محتوا

برای افزودن یا اصلاح محتوای آموزشی:

- فایل را در پوشهٔ فناوری و موضوع مرتبط قرار دهید و نام‌گذاری موجود را تا حد امکان حفظ کنید.
- مثال را با مرورگر اجرا کنید و مطمئن شوید خطای واضحی در Console ندارد.
- اگر مثال به API، اینترنت یا ابزار خاصی نیاز دارد، پیش‌نیاز آن را در همان درس مشخص کنید.
- فایل‌های اصلی آموزشی را حذف یا جابه‌جا نکنید مگر آن‌که جایگزینی روشن و کامل برایشان فراهم شده باشد.
- هنگام بازبینی، پیوندهای نسبی، نمایش فارسی و راست‌به‌چپ، و خوانایی کدهای چپ‌به‌راست را نیز کنترل کنید.
