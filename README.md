# دورهٔ آموزش JavaScript

این پوشه مواد آموزشی دورهٔ JavaScript را در یک مسیر گردآوری می‌کند: جزوه‌های جلسه‌ها، نسخه‌های PDF، مثال‌ها و تمرین‌های قابل‌اجرا در مرورگر، سرفصل دوره و برگهٔ مرجع JavaScript.

## شروع سریع

۱. برای دیدن نمای کلی دوره، فایل `JavaScript.pdf` را باز کنید.
۲. برای مطالعهٔ یک موضوع، وارد پوشهٔ شماره‌دار همان جلسه شوید و جزوهٔ همان جلسه را مطالعه کنید.
۳. برای اجرای مثال‌ها، فایل‌های `.html` داخل پوشهٔ `تمرین` را در مرورگر باز کنید.
۴. اگر نمونه‌ای از API یا دادهٔ اینترنتی استفاده می‌کند، اتصال اینترنت را برقرار کنید. اگر مرورگر به‌دلیل محدودیت `file://` اجازهٔ درخواست نداد، فایل را با یک سرور محلی مانند Live Server در VS Code اجرا کنید.

## مسیر جلسه‌ها

جلسه‌ها به ترتیب زیر چیده شده‌اند:

1. مقدمه و مسیر یادگیری JavaScript
2. آشنایی با متغیرها، داده‌ها و توابع
3. عملگرها در JavaScript
4. رشته‌ها و متدهای آن‌ها (Strings)
5. آرایه‌ها (Arrays)
6. کنترل روند اجرای برنامه (Control Structures)
7. زمان و تاریخ (Date & Time)
8. JSON و تبادل داده‌ها
9. کار با APIها، Fetch و Ajax
10. برنامه‌نویسی ناهم‌زمان با Promise و Async/Await
11. شی‌گرایی و کلاس‌ها (OOP)
12. کار با اشیاء پیشرفته در JavaScript
13. کار با مجموعه‌های Set و Map
14. عبارات باقاعده (Regular Expressions)
15. کار با مدل DOM
16. کار با رویدادها در JavaScript
17. مدل BOM (Browser Object Model)
18. کار با کوکی‌ها و Local Storage
19. مدیریت خطاها (Error Handling)
20. مدیریت خطاهای پیشرفته در JavaScript
21. مدل اجرا و چرخهٔ رخدادها (Event Loop)
22. توابع بازگشتی و توابع مرتبه‌بالا
23. بهترین شیوه‌ها در کدنویسی JavaScript
24. پروژهٔ نهایی JavaScript
25. کار با کتابخانهٔ jQuery

بهتر است جلسه‌ها را به همین ترتیب پیش بروید؛ موضوعاتی مانند DOM، درخواست‌های شبکه و برنامه‌نویسی ناهم‌زمان بر مفاهیم پایه‌تر تکیه دارند.

## ساختار هر جلسه

ساختار دقیق پوشه‌ها با توجه به موضوع کمی تفاوت دارد، اما معمولاً شامل این موارد است:

- جزوهٔ آموزشی هر جلسه.
- فایل `.pdf`: نسخهٔ قابل‌مطالعه یا چاپ جزوه، در جلسه‌هایی که PDF آن تهیه شده است.
- پوشهٔ `تمرین`: مثال‌های HTML برای اجرا و بررسی عملی موضوع.

فایل HTML را در مرورگر باز کنید. برای دیدن پیام‌های `console.log`، ابزار توسعه‌دهندهٔ مرورگر را با کلید `F12` باز کرده و زبانهٔ **Console** را انتخاب کنید. برای تغییر نمونه، فایل را در یک ویرایشگر کد مانند VS Code باز کنید، ذخیره کنید و صفحهٔ مرورگر را تازه‌سازی کنید.

## پیش‌نیاز و ابزار

- آشنایی مقدماتی با HTML و CSS برای مثال‌هایی که صفحهٔ وب را تغییر می‌دهند.
- مرورگر به‌روز و یک ویرایشگر متن یا کد.
- اینترنت برای نمونه‌هایی که به API یا کتابخانهٔ آنلاین متصل می‌شوند.

برای بیشتر مثال‌های سمت مرورگر، نصب Node.js یا ابزار ساخت لازم نیست. اگر پروژه‌ای به ابزار یا محیط دیگری نیاز داشته باشد، همان پروژه باید روش اجرای خود را مشخص کند.


## نگهداری و افزودن مثال

فایل آموزشی یا تمرین جدید را کنار جلسهٔ مرتبط قرار دهید، نام‌گذاری شماره‌دار موجود را حفظ کنید و پیش از افزودن، مثال HTML را در مرورگر اجرا کنید. در نمونه‌هایی که به اینترنت، API یا راه‌اندازی سرور نیاز دارند، نیازمندی اجرا را در همان فایل یا جزوه ذکر کنید.
